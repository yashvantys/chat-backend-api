
# Chat Backend (Node.js + TypeScript + PostgreSQL + Firestore)

A chat backend supporting 1:1 conversations, message delivery, ordered message retrieval, read receipts, and last-seen tracking.

## Setup

```bash
npm install
cp .env.example .env
docker compose up -d
npm run dev
```

Docker Compose starts PostgreSQL, initializes the database schema, and creates three seed users.

### Environment variables

Configure the following in `.env`:

```env
PORT=3000
DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@localhost:5432/chat_db?schema=public
FIREBASE_PROJECT_ID=your-firebase-project-id
GOOGLE_APPLICATION_CREDENTIALS=./serviceAccount.json
```

### Firestore configuration

Choose either option:

**Option 1: Firebase service account**

Set `GOOGLE_APPLICATION_CREDENTIALS` to the path of your Firebase service-account JSON file.

**Option 2: Firebase Emulator**

Start the Firestore emulator:

```bash
firebase emulators:start --only firestore
```

Set:

```env
FIRESTORE_EMULATOR_HOST=localhost:8080
FIREBASE_PROJECT_ID=chat-demo
```

Never commit `.env` or service-account credentials to Git.

## Data model

### PostgreSQL

PostgreSQL stores relational data:

- `users`: user information.
- `chats`: conversation information.
- `chat_members`: chat membership information.

**Duplicate 1:1 chat prevention**

The `direct_key` column has a UNIQUE constraint.

The key is generated by sorting the two user IDs:

```text
direct_key = sorted(userAId, userBId).join(":")
```

This ensures that the same pair of users cannot create duplicate direct chats, including concurrent creation requests.

### Firestore

Firestore stores messages and read-related information.

**Messages**

```text
chats/{chatId}/messages/{messageId}
```

Document fields:

```text
senderId
text
createdAt
editedAt
deleted
readBy
```

- `createdAt`: Firestore server timestamp.
- `editedAt`: timestamp of the last edit.
- `deleted`: soft-delete status.
- `readBy`: map of user IDs to read timestamps.

**Member last-seen information**

```text
chats/{chatId}/members/{userId}
```

Document fields:

```text
lastSeenMessageId
lastSeenMessageAt
updatedAt
```

## API documentation

Base URL:

```text
http://localhost:3000
```

| Method | Endpoint | Request |
|---|---|---|
| POST | `/chat/create` | `{ "userAId": "...", "userBId": "..." }` |
| POST | `/chat/:chatId/message/send` | `{ "senderId": "...", "text": "Hello" }` |
| GET | `/chat/:chatId/messages` | `userId`, `limit`, optional `before` query parameters |
| POST | `/chat/:chatId/message/:messageId/read` | `{ "userId": "..." }` |
| POST | `/chat/:chatId/lastseen` | `{ "userId": "...", "messageId": "..." }` |
| GET | `/user/:userId/chats` | User ID in URL |
| PATCH | `/chat/:chatId/message/:messageId` | `{ "senderId": "...", "text": "Updated message" }` |
| DELETE | `/chat/:chatId/message/:messageId` | `senderId` query parameter |

### API details

**1. Create or retrieve a direct chat**

```http
POST /chat/create
```

Request:

```json
{
  "userAId": "11111111-1111-4111-8111-111111111111",
  "userBId": "22222222-2222-4222-8222-222222222222"
}
```

Response:

```json
{
  "chatId": "generated-chat-uuid",
  "created": true
}
```

**2. Send a message**

```http
POST /chat/{chatId}/message/send
```

Request:

```json
{
  "senderId": "11111111-1111-4111-8111-111111111111",
  "text": "Hello Bob!"
}
```

**3. Retrieve messages**

```http
GET /chat/{chatId}/messages?userId=11111111-1111-4111-8111-111111111111&limit=50
```

Optional pagination:

```http
GET /chat/{chatId}/messages?userId=11111111-1111-4111-8111-111111111111&limit=50&before=2026-11-19T10:00:00.000Z
```

Messages are returned in chronological order (oldest to newest).

**4. Mark a message as read**

```http
POST /chat/{chatId}/message/{messageId}/read
```

Request:

```json
{
  "userId": "22222222-2222-4222-8222-222222222222"
}
```

**5. Update last seen**

```http
POST /chat/{chatId}/lastseen
```

Request:

```json
{
  "userId": "22222222-2222-4222-8222-222222222222",
  "messageId": "firestore-message-id"
}
```

**6. List user chats**

```http
GET /user/11111111-1111-4111-8111-111111111111/chats
```

Returns the user's chats with member IDs.

**7. Edit a message (Bonus)**

```http
PATCH /chat/{chatId}/message/{messageId}
```

Request:

```json
{
  "senderId": "11111111-1111-4111-8111-111111111111",
  "text": "Updated message"
}
```

**8. Delete a message (Bonus)**

```http
DELETE /chat/{chatId}/message/{messageId}?senderId=11111111-1111-4111-8111-111111111111
```

Messages are soft-deleted. The document remains in Firestore, but its text is removed.

## Try it

Create a chat between Alice and Bob:

```bash
curl -X POST http://localhost:3000/chat/create \
  -H "Content-Type: application/json" \
  -d '{
    "userAId": "11111111-1111-4111-8111-111111111111",
    "userBId": "22222222-2222-4222-8222-222222222222"
  }'
```

Send a message using the returned `chatId`:

```bash
curl -X POST http://localhost:3000/chat/CHAT_ID/message/send \
  -H "Content-Type: application/json" \
  -d '{
    "senderId": "11111111-1111-4111-8111-111111111111",
    "text": "Hello Bob!"
  }'
```

Retrieve messages:

```bash
curl "http://localhost:3000/chat/CHAT_ID/messages?userId=11111111-1111-4111-8111-111111111111&limit=50"
```
